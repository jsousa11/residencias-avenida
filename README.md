# Residências Avenida

Site de venda em planta de três apartamentos na Rua do Mercado, Vila do Porto (Santa Maria, Açores).

## Desenvolvimento

```
npm install
npm run dev
```

Os textos, apartamentos, áreas, preços e contactos estão todos em `src/data.js`.

## Publicação

O Netlify compila e publica sozinho a cada `git push` para `main` (ver `netlify.toml`).
